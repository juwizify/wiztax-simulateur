**Suppressions** :
- `fcpi` (classique) : non éligible IR-PME depuis 21/02/2026

## Contraintes spéciales du moteur

1. **Plafond annuel partagé** entre `irPmeJei` (versement direct) et `fcpiJei` (via fonds) : le cumul des versements ≤ 75 000 € (cél) ou 150 000 € (couple). Si dépassement, la part en surplus n'ouvre pas droit à RI.
2. **Plafond pluri-annuel** : la RI cumulée `irPmeJei` + `irPmeJeir` sur 2024-2028 ne peut pas dépasser 50 000 €.
   → Modélisation : input optionnel `irPmeJeiJeirImputeAnterieur` (€) en mode complet ; le moteur cape la nouvelle RI 2026 à (50 000 − imputé antérieur).
3. **ESUS post 1/10/2026** : taux 25 % subordonné à validation Commission européenne. Pour le simulateur : on conserve 25 % et on ajoute un warning visible sur les versements postérieurs au 1/10/2026.

## Modèle de données

```js
input.irPmeLignes = [
  { type: 'pme-standard', montant: 5000 },   // → RI = 5000 × 18 %  = 900 €
  { type: 'jei',          montant: 30000 },  // → RI = 30000 × 30 % = 9000 €  (cap partagé JEI)
  { type: 'fcpi-jei',     montant: 50000 },  // → RI = 50000 × 30 % = 15000 € (cap partagé JEI : 30+50=80k > 75k cél → tronqué)
  { type: 'jeir',         montant: 10000 },  // → RI = 10000 × 50 % = 5000 €
  // ...
]
input.irPmeJeiJeirImputeAnterieur = 0  // RI JEI+JEIR déjà imputée sur 2024-2025 (mode complet uniquement)
```

Types valides : `pme-standard`, `esus`, `mh`, `jei`, `fcpi-jei`, `jeii`, `jeir`.
